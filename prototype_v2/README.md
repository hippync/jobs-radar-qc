# Prototype V2

This folder contains static design prototype screenshots for the Jobs Radar QC interface. These files are reference assets only; they are not part of the running application code.

## Structure

- `web/` - desktop web mockups at `3840 x 2760`.
- `app/` - mobile app mockups at `1125 x 2280`.

## Web Screens

- `Homepage.png` - desktop home screen concept.
- `Saved _board_.png` - desktop saved jobs board concept.
- `Tech Radar.png` - desktop tech radar view.
- `Tech Radar_B.png` - alternate desktop tech radar view.

## Mobile Screens

- `Mobile Home.png` - mobile home screen concept.
- `Mobile Saved.png` - mobile saved jobs screen concept.
- `Mobile Radar.png` - mobile tech radar view.
- `Mobile Radar_B.png` - alternate mobile tech radar view.

## Usage

Use these images as visual guidance when implementing or reviewing frontend screens, layout decisions, responsive behavior, and product direction. The active frontend implementation lives separately in `frontend/`.
